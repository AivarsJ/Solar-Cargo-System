# Projekta nosaukums

**Solar Cargo System**

# Projekta apraksts

Solar Cargo System ir kosmisko pārvadājumu konteineru uzskaites sistēmas projekts. 
Sistēmas mērķis ir nodrošināt konteineru un to kravu uzskaiti, sistematizēt informāciju un palīdzēt sekot konteineru 
kustībai starp izcelsmes un galamērķa bāzēm.

Projekts pašlaik ir izstrādes stadijā un realizēts kā HTML un CSS tīmekļa vietnes prototips.

# Funkcionalitāte

Pašreizējā projekta versijā ir izveidotas šādas sadaļas:

- sākumlapa ar sistēmas aprakstu un navigāciju;
- konteineru saraksta attēlošana;
- jauna konteinera ievades forma;
- konteinera ID, minerāla, izcelsmes bāzes, galamērķa bāzes un statusa ievade;
- statistikas sadaļa.

Projektā paredzēts turpināt izstrādāt konteineru meklēšanu, datu saglabāšanu un apstrādi, ierakstu labošanu un dzēšanu, 
kā arī lietotāju un piekļuves tiesību pārvaldību.

# Kā palaist projektu

Projekts ir publicēts **InfinityFree** tīmekļa hostingā, tāpēc tā apskatei nav nepieciešams projektu lejupielādēt vai lokāli palaist.

Publicēto projektu var atvērt tīmekļa pārlūkprogrammā:

**https://zemesdiena.id.lv**

Lokālai projekta apskatei:

1. Lejupielādēt vai noklonēt projekta failus.
2. Pārliecināties, ka HTML faili un `style.css` atrodas atbilstošajās projekta direktorijās.
3. Atvērt `index.html` tīmekļa pārlūkprogrammā.
4. No sākumlapas izmantot navigācijas saites, lai atvērtu konteineru sarakstu, konteinera pievienošanas formu vai statistikas sadaļu.

Pašreizējai statiskajai projekta versijai nav nepieciešama datubāze vai lokāls tīmekļa serveris.
